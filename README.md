# 吕颖瑜个人网站

可直接本地预览的静态网站，无需安装依赖。

## 个人定位

**一句话定位：**以工商管理的系统训练为基础，具备跨学科视角、善用 AI 工具推进研究、产品与策略实践的商科生。

网页以商业基础、AI 应用和跨学科实践作为统一叙事。商业基础和项目经历依据简历；AI 工具能力依据用户补充的个人定位表达，不额外编造工具、技能证书或已上线成果。

## 预览

在此文件夹运行：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。入口页为 `index.html`，点击「进入作品集」后到 `portfolio.html`。

## 内容结构

| 顺序 | 页面 / 模块 | 内容目的 | 素材来源 |
| --- | --- | --- | --- |
| 入口 | 视觉入口 | 抽象液态玻璃球视觉，配合“从洞察到行动”与进入按钮 | 用户的视觉方向与个人定位 |
| 00 | Hero | “AI+商科”定位、跨学科商科背景与行业研究、市场策略、用户分析方向；右侧项目地图可查看项目名称并跳转到卡片 | 用户提供的首屏文案、交互方案与个人定位 |
| 01 | 关于我 | 彩色人像、介绍、联系方式、综测排名、专业绩点排名、六级成绩与经历速览 | 用户人像、中英文简历及用户补充的学业数据 |
| 02 | 升学路径 | 四个学校阶段与对应年份组成一张路径图，飞机沿路径跟随鼠标移动 | 用户提供的学校和年份 |
| 03 | 核心课程 | 21 门核心课程组成可交互的 3D 玻璃球形词云，承接升学路径并引出项目实践 | 用户提供的课程名称 |
| 04 | 精选项目 | 先展示明阳智能策略与致景科技案例分析，再呈现 AI 医患互动研究和 MoodBox 产品实践；四个项目统一放入横向卡片画廊 | 用户演示视频、交互参考视频、中英文简历、商业计划书 |
| 05 | 个人荣誉 | 展示 3 项个人奖学金或竞赛奖、2 项团队项目荣誉、1 项志愿服务荣誉，并标明归属 | 中英文简历 |
| 收尾 | 联系方式 | 在页尾再次提供邮箱入口 | 用户提供的联系方式 |

项目说明严格区分 MVP / 研究 / 战略分析的真实阶段。尚未收到额外网页代码或视觉参考，当前版本采用原生 HTML、CSS、JavaScript，便于后续替换图片、文案和组件。

## 设计规范

| 项目 | 桌面端 | 移动端 |
| --- | --- | --- |
| 布局 | 最大内容宽度 1380px；两列介绍、横向项目卡片画廊、纵向荣誉列表 | 项目画廊露出下一张卡片以提示滑动；23px 页面边距；940px 以下折叠导航 |
| 字级 | 首屏保留展示型大标题；内容模块标题统一为 42–64px、卡片标题 28px、板块说明 15px | 内容模块标题统一为 36–54px、卡片标题 22–25px、板块说明 14px |
| 色彩与质感 | 暖白为统一底色，雾紫、浅蓝、暖杏与陶土色分别强调不同板块；正文使用深墨紫。课程区用局部深紫衬托玻璃球的透明折射，保留彩色人像 | 球体与文字随屏宽缩放；作品页保持清楚的文字对比 |
| 间距 | 模块纵向约 100–172px；卡片间距 24px | 模块纵向 88px；卡片顺序堆叠 |
| 交互 | 顶部导航固定在视窗同一位置，锚点跳转避开导航；项目画廊可拖动、按左右按钮或方向键浏览，点击卡片打开详情；MoodBox 视频只在可见且允许动态效果时静音循环；鼠标移动使飞机沿升学路径前进，点击节点可定位到该阶段 | 顶部导航保持固定，画廊可触摸滑动，升学路径改为纵向，点击节点可定位飞机；视频保留静态封面并可在详情中手动播放 |
| 动效 | 课程球体随鼠标水平移动只绕竖直中心轴旋转，停止移动后平稳停下；背面文字透过玻璃隐约可见；飞机与已走路径同步移动 | 球体按屏宽重新排列文字，避免重叠；遵循系统「减少动态效果」设置 |

视觉参考采用 [Apple 官网](https://www.apple.com/)的大留白、明确的信息层级与克制的按钮反馈；本站保留自己的玻璃项目地图、色彩分区和商科 × AI 内容结构。主操作使用深墨紫圆角矩形，画廊方向按钮保留左右箭头以说明操作，其余纯装饰箭头已移除。

## 文件

- `index.html`：视觉入口页。
- `portfolio.html`：完整作品站。
- `styles.css`：全站样式与响应式规则。
- `liquid.css`：作品页的液态玻璃视觉层与移动端适配。
- `course-orb.css`：作品页课程区的局部深色视觉与球体响应式布局。
- `typography.css`：作品页统一的响应式标题、正文与标签字级。
- `project-cards.css`：横向项目画廊、卡片和详情弹层内容样式。
- `project-map.css`：首屏交互式项目地图、玻璃节点与移动端布局。
- `visual-refresh.css`：入口与作品页共用的色彩系统、板块渐变衔接与玻璃材质。
- `course-orb.js`：课程球体投影、玻璃绘制与文字防重叠布局。
- `main.js`：移动菜单、升学路径飞机跟随、项目详情弹层与视频可见性控制。
- `assets/yingyu-portrait.webp`：由提供的人像照裁切压缩。
- `assets/moodbox-demo.mp4`：提供的 MoodBox 演示视频副本。
- `assets/moodbox-poster.svg`：MoodBox 演示视频静态封面。

## 后续替换

升学路径是抽象信息图。后续若提供校园或作品截图、网页代码和参考网站，可继续细化路径视觉与项目媒体区。当前网站不依赖构建工具，可直接部署到任何静态托管服务。
